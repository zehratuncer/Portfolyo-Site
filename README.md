## 📂 Projeler ve Çalışmalar

1. **🏢 TOFAŞ Staj Projesi 1 — Bayi Doküman & Duyuru Yönetim Portalı**
   - *.NET 9 Web API, Clean Architecture, PostgreSQL, JWT Authentication, Role-Based Authorization, Soft Delete.*
   - Bayilerin yalnızca yetkili oldukları markalara özel dokümanlara erişebildiği kurumsal portal.
2. **🏢 TOFAŞ Staj Projesi 2 — Kurumsal İçerik & İş Akışı Portalı (M-Files Esinlenmeli)**
   - *Angular 20 Standalone, Signals, Materialized ObjectACL, WebDAV, Dynamic Metadata Form, Audit Trail.*
   - Klasörsüz nesne modeli, sürümleme, check-out kilitleme ve SLA takipli iş akışları sunan kurumsal içerik yönetim platformu.
3. **🧪 TÜBİTAK 2209-A — Göz Takibi & Nöropazarlama Isı Haritası Analizi**
   - *Python, OpenCV, MediaPipe.*
   - Web kamerası verileriyle göz hareketlerini analiz eden ve görsel dikkat odağını haritalandıran bilimsel araştırma projesi.
4. **📱 Be Yourself — Dijital Moda & Stil Uygulaması**
   - *Flutter & Dart.*
   - Kişiselleştirilmiş kombin önerileri ve tarz takibi sunan mobil uygulama.
5. **🧮 Not Hesaplama Uygulaması**
   - *C# .NET WinForms.*
   - Vize, ödev ve etki oranlarına göre dönem sonu bağıl/hedef sınav puanını hesaplayan masaüstü yazılımı.
6. **🐦 Twitter Klonu & 🃏 Kart Oyunu & 🚗 Driver App**
   - Sosyal etkileşim, oyun mantığı ve rota/veri takibine dayalı uygulama projeleri.

## 💻 Yerel Kurulum & Çalıştırma

Projeyi yerel bilgisayarınızda çalıştırmak için herhangi bir derleyiciye veya paket yöneticisine ihtiyacınız yoktur.

1. Projeyi klonlayın:
   ```bash
   git clone https://github.com/zehratuncer/Portfolyo_Site.git
   ```
2. Proje dizinine gidin:
   ```bash
   cd Portfolyo_Site
   ```
3. `index.html` dosyasını tarayıcınızda açın veya VS Code **Live Server** eklentisi ile başlatın.
