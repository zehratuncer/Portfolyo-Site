# C# WindowsForm - Not Hesaplama Uygulaması
Dersten geçmek için minimum notu hesaplayan bir araç. 

## 🔹 Özellikler
- Vize, ödev yüzdelerini ve notlarını girebilme
- Ödevleri istersen boş bırakarak 0 olarak değerlendirebilme
- Finalde minimum kaç alınması gerektiğine dair anında hesaplama 
- C# WinForms arayüzü ile kolay kullanım

## 🔹 Teknoloji
- C#
- .NET WinForms

## 🔹 Kurulum
1. Repo’yu bilgisayarınıza klonlayın.
```bash
git clone https://github.com/zehratuncer/not_hesaplama_uygulamasi.git
Visual Studio’da açın.

not_hesaplama_uygulamasi.sln dosyasını çalıştırın.

## C# WindowsForm - Grade Calculator Application
A tool that calculates the minimum grade to pass a course.

## 🔹 Features
- Ability to enter midterm and homework percentages and grades
- Ability to rate assignments as 0 by leaving them blank if you want
- Instant calculation of the minimum score for the final exam 
- Easy to use with C# WinForms interface

## 🔹 Technology
- C#
- .NET WinForms
